## 1. Контекст

Премиальный жилой комплекс в Мещерском парке (Москва) открывает отдел продаж. Менеджеру нужен инструмент на планшете для показа курированных видеопрезентаций на большом ТВ-экране во время встреч с клиентами. Система должна быть интуитивной — одно нажатие меняет нарратив на экране.

**Не публичное приложение.** Публикация в App Store не требуется. Внутренний инструмент для одного офиса продаж.

---

## 2. Цели

- Менеджер выбирает сценарий образа жизни на планшете → экран показывает соответствующий контент
- 20–25 коротких видео (≤30с), организованных в 5 сценариев
- Контент обновляется без участия разработчика
- Работает на iPad (основной) и Android-планшете (вторичный)
- Беспроводное зеркалирование на офисный ТВ

**Не-цели:**
- Публикация в App Store
- Аутентификация пользователей (режим киоска, всегда включён)
- Офлайн-режим (стабильный интернет в офисе)
- Аналитика (возможно в будущей итерации)

## 4. Технологические решения

### 4.1 Swift 6.3 + SwiftUI (основная платформа iOS)

**Решение:** Основное приложение на Swift 6.3 с SwiftUI и компонентами Liquid Glass (iOS/iPadOS 26).

**Обоснование:**
- В офисе продаж клиента, скорее всего, будет iPad (экосистема Apple доминирует в российском люксовом сегменте)
- Строгий контроль параллелизма Swift 6.3 устраняет гонки данных при асинхронной загрузке видео
- UI Liquid Glass соответствует премиальной эстетике проекта
- iPadOS 26 обеспечивает лучшее управление внешним дисплеем

**Рассмотренные альтернативы:**
- React Native — отклонено (нет поддержки Liquid Glass, хуже нативное ощущение)
- Flutter — отклонено (по тем же причинам, плюс клиент — iOS-first)

---

### 4.2 SKIP для транспиляции под Android

**Решение:** Использовать [SKIP](https://skip.tools) для транспиляции кода Swift/SwiftUI в Kotlin/Jetpack Compose.

**Обоснование:**
- Единая кодовая база для iOS + Android снижает затраты на поддержку
- Деплой Android — только APK сайдлоад, без рисков ревью Google Play
- Клиент может использовать Android TV экран с Android-планшетом в качестве контроллера
- SKIP быстро развивается; простой UI плеера хорошо укладывается в его возможности

**Риск:** SKIP относительно новый. Митигация: iOS — основная платформа; Android вторичен и может откатиться к упрощённому веб-отображению при блокерах SKIP.

---

### 4.3 Supabase как бэкенд

**Решение:** Supabase (PostgreSQL + Storage + Edge Functions) как единый бэкенд.

**Обоснование:**
- Будущие проекты (приложение жителей, CRM для персонала) будут использовать этот инстанс — инвестируем один раз
- Supabase Storage обеспечивает CDN-доставку видео
- Дашборд Supabase служит CMS без создания кастомного админ-интерфейса
- Бесплатного тарифа достаточно для масштаба проекта

**Схема:**
```sql
scenarios (id, title, slug, order_index, active)
videos (id, scenario_id, title, storage_path, duration_sec, order_index, active)
```

---

### 4.4 GitHub Actions для бэкапов

**Решение:** Ежедневный автоматический pg_dump через GitHub Actions, коммит в ветку `backups/`.

**Обоснование:**
- Нулевые дополнительные затраты (бесплатные минуты GitHub Actions)
- Простая, аудируемая история бэкапов в git
- Данные клиента критичны (будущие данные жителей и сервисов)

```yaml
on:
  schedule:
    - cron: '0 2 * * *'
```

---

### 4.5 Беспроводное зеркалирование дисплея

**Решение:** AirPlay (iOS) / Cast (Android) для зеркалирования экрана — без HDMI.

**Обоснование:**
- Клиент явно запросил беспроводное подключение
- Менеджер перемещается вокруг стола во время презентаций
- AirPlay нативно поддерживается iPadOS; предполагается Apple TV или AirPlay-совместимый ТВ

**Риск:** Зависимость от сети. Митигация: обеспечить в офисе продаж выделенную локальную WiFi-сеть для AirPlay.

## 6. Деплой

| Платформа | Способ | Примечания |
|---|---|---|
| iOS / iPadOS | TestFlight | Без ревью App Store. Ссылка отправляется клиенту. |
| Android | APK сайдлоад | `adb install Showcase.apk` или прямая передача файла |
| Бэкенд | Supabase cloud | Управляемый, без необходимости самохостинга |
| CI/CD | GitHub Actions | Только бэкап-воркфлоу |

**Apple Developer Program:** Требуется для TestFlight. Стоимость: $99/год. Клиент предоставляет иностранную карту или разработчик использует свой аккаунт с передачей.

---

## 8. Безопасность

- **Без аутентификации в приложении** — режим киоска, всегда включён
- **Supabase RLS:** `videos` и `scenarios` — SELECT для анонимных, всё для `service_role`
- **Доступ к CMS:** Дашборд Supabase, учётные данные администратора у команды разработки
- **Секреты:** `SUPABASE_DB_URL`, `SUPABASE_ANON_KEY` хранятся в GitHub Secrets
