## 1. Философия дизайна

**Одно правило:** Менеджер не должен чувствовать, что он работает с программой. Он должен ощущать, что ведёт разговор.

Интерфейс исчезает. Контент берёт верх. Экран телевизора становится частью комнаты.

**Эстетическое направление:** Тихая роскошь. Архитектурная сдержанность. UI существует на периферии — появляется, когда нужен, отступает, когда нет. Поверхности Liquid Glass ощущаются как матовый камень, а не стеклянные пузыри.

## 2. Токены бренда

### Цвета

```swift
// Дизайн-токены — соответствуют бренд-платформе Соль Девелопмент
extension Color {
    // Основные
    static let ink        = Color(hex: "#1A1A2E")  // Угольный — основной текст, тёмные поверхности
    static let white      = Color(hex: "#FFFFFF")   // Белый — светлые поверхности
    static let soft       = Color(hex: "#F7F5F2")   // Мягкий — тёплый фон

    // Акцентные
    static let terracotta = Color(hex: "#C0392B")   // Терракота — основной акцент, CTA
    static let ochre      = Color(hex: "#C8A96E")   // Охра — вторичный тёплый акцент

    // Нейтральные
    static let mid        = Color(hex: "#8A8880")   // Средний — подписи, метаданные
    static let line       = Color(hex: "#1A1A2E").opacity(0.1)  // Разделители

    // Тинты Liquid Glass (iPadOS 26)
    static let glassTint  = Color(hex: "#1A1A2E").opacity(0.04)
    static let glassStroke = Color(hex: "#1A1A2E").opacity(0.12)
}
```

### 4.1 Главный экран — Сетка сценариев

**Назначение:** Домашняя база менеджера. Выбор сценария образа жизни для начала презентации.

```
│  │          │  │          │  │          │               │
│  │  СЕМЬЯ   │  │ ЗДОРОВЬЕ │  │  ГОСТИ   │               │  ← Карточки сценариев
│  │          │  │          │  │          │               │     3 верхний ряд
│  └──────────┘  └──────────┘  └──────────┘               │
│                                                          │
│           ┌──────────┐  ┌──────────┐                    │
│           │          │  │          │                    │
│           │ ИНВЕСТОР │  │ АРХИТЕК- │                    │  ← 2 нижний ряд
│           │          │  │  ТУРА    │                    │     по центру
│           └──────────┘  └──────────┘                    │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**Спецификация карточки сценария:**
- Размер: ~280×200pt
- Фон: Liquid Glass поверхность (`.ultraThinMaterial`)
- Верх: стоп-кадр сценария (миниатюра видео)
- Нижний оверлей: название сценария (Display Small) + количество видео (Body Small, терракота)
- Активное состояние: рамка терракота (1.5pt) + лёгкое масштабирование (1.02)
- Нажатие: `.scaleEffect(0.97)` пружинная анимация

**Навигационная панель:**
- Liquid Glass стиль `.bar`
- Слева: логотип Showcase (кастомный SVG)
- Справа: иконка каталога (SF Symbol `square.grid.2x2`)
- Без кнопки «назад» на главной

## 5. Библиотека компонентов

### 5.1 ScenarioCard

```swift
struct ScenarioCard: View {
    let scenario: Scenario
    let isActive: Bool

    var body: some View {
        ZStack(alignment: .bottomLeading) {
            // Миниатюра
            AsyncImage(url: scenario.thumbnailURL)
                .aspectRatio(14/10, contentMode: .fill)

            // Градиентный оверлей
            LinearGradient(
                colors: [.clear, Color.ink.opacity(0.7)],
                startPoint: .center,
                endPoint: .bottom
            )

            // Текст
            VStack(alignment: .leading, spacing: 4) {
                Text(scenario.title.uppercased())
                    .font(.labelCaps)
                    .tracking(2)
                    .foregroundColor(.white)
                Text("\(scenario.videoCount) видео")
                    .font(.bodySmall)
                    .foregroundColor(.terracotta)
            }
            .padding(20)
        }
        .clipShape(RoundedRectangle(cornerRadius: 12))
        .overlay(
            RoundedRectangle(cornerRadius: 12)
                .stroke(isActive ? Color.terracotta : Color.clear, lineWidth: 1.5)
        )
        .scaleEffect(isActive ? 1.02 : 1.0)
        .animation(.spring(response: 0.3, dampingFraction: 0.7), value: isActive)
    }
}
```

### 5.3 Кнопка управления

```swift
struct ControlButton: View {
    let symbol: String
    let label: String
    let action: () -> Void
    var isPrimary: Bool = false

    var body: some View {
        Button(action: action) {
            VStack(spacing: 6) {
                Image(systemName: symbol)
                    .font(.system(size: isPrimary ? 28 : 20, weight: .light))
                Text(label)
                    .font(.labelCaps)
                    .tracking(1.5)
            }
            .foregroundColor(isPrimary ? .white : .ink)
            .frame(width: isPrimary ? 100 : 80, height: isPrimary ? 100 : 80)
            .background(isPrimary ? Color.terracotta : Color.glassStroke)
            .clipShape(RoundedRectangle(cornerRadius: isPrimary ? 20 : 16))
        }
        .buttonStyle(.plain)
    }
}
```

### 5.4 VideoRow (Каталог)

```swift
struct VideoRow: View {
    let video: Video
    let onPlay: () -> Void

    var body: some View {
        HStack(spacing: 16) {
            AsyncImage(url: video.thumbnailURL)
                .frame(width: 96, height: 60)

                .foregroundColor(.mid)

            Button(action: onPlay) {
                Image(systemName: "play.circle")
                    .font(.system(size: 28, weight: .light))
                    .foregroundColor(.terracotta)
            }
            .buttonStyle(.plain)
        }
        .padding(.vertical, 12)
    }
}
```

## 6. Движение и анимация

### Принципы
- **Пружина везде** — `response: 0.3–0.5, dampingFraction: 0.7–0.8`
- **Без резкости** — максимум 400мс на любой переход
- **Направленность** — контент входит снизу/справа, выходит наверх/влево

### Ключевые анимации

| Взаимодействие | Анимация |
|---|---|
| Нажатие на карточку сценария | Масштаб 1.0 → 0.96 → переход к плееру |
| Переход между экранами | `.navigationTransition(.zoom)` (iPadOS 26) |
| Старт видео на ТВ | Кроссфейд 0.6с |
| Автоплей следующего видео | Затухание → появление 0.4с |
| Состояние загрузки | Пульсация (opacity 1.0 → 0.4 → 1.0, 1.2с повтор) |
| Рамка активной карточки | `.animation(.spring, value: isActive)` |

## 7. Доступность

- Все интерактивные элементы: минимум 44×44pt область нажатия
- VoiceOver-метки на всех кнопках и изображениях
- Dynamic Type: стили Body масштабируются; стили Display фиксированы
- Режим высокой контрастности: рамки усиливаются до 2pt, фоны затемняются
- Режим Reduce Motion: кроссфейды заменяют все пружинные/масштабные анимации

## 8. Правила использования Liquid Glass

✅ **Использовать для:**
- Навигационных панелей
- Оверлеев карточек сценариев
- Модальных окон
- Фона панели управления

❌ **Не использовать для:**
- Основных CTA-кнопок (использовать сплошную терракоту)
- Текстовых контейнеров (читаемость)
- Элементов управления видеоплеера на ТВ (невидимы)

## 10. Заметки для передачи дизайн → разработка

- Все цвета используются по имени токена (см. §2)
- Шрифты загружаются через `CTFontManager` (Cormorant Garamond + Jost встроены в приложение)
- Liquid Glass: использовать `.ultraThinMaterial` + кастомный тинт-оверлей — НЕ имитировать хаками с прозрачностью
- Радиус скругления: 8pt (малый) · 12pt (карточка) · 20pt (большая кнопка) · 28pt (модальное окно)
- Все изображения: `AsyncImage` с `.fill` content mode + шиммер-заглушка
- Тени: отсутствуют — глубина достигается через слои Liquid Glass
