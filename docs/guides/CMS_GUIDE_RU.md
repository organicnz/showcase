# CMS Guide — Showcase Мещерского парка

Данное руководство предназначено для администраторов проекта «Showcase» (ООО «СПК-М»). Здесь описаны процессы управления контентом через панель управления Supabase.

---

## 1. Доступ к панели управления

**URL:** [https://supabase.com/dashboard](https://supabase.com/dashboard)  
**Проект:** `showcase-meshchersky`  
**Раздел:** Table Editor (для метаданных) и Storage (для файлов).

---

## 2. Управление Сценариями (`scenarios`)

Таблица `scenarios` определяет главные карточки на домашнем экране.

| Поле | Описание | Пример |
|---|---|---|
| `title` | Название сценария (Display font) | Семья с детьми |
| `slug` | Технический ID (маленькие буквы, без пробелов) | `family` |
| `description` | Краткое описание (Body font) | Безопасность и комьюнити... |
| `icon_name` | Название SF Symbol | `figure.2.and.child.holdinghands` |
| `ambient_audio_path` | Путь к аудиофайлу в Storage (`assets/audio/`) | `family_ambient.m4a` |
| `active` | Флаг видимости в приложении | `true` |

---

## 3. Управление Видео (`videos`)

Видео подгружаются динамически внутри выбранного сценария.

### Технические требования к видео (Важно!):
Для сохранения «Тихой роскоши» и плавности воспроизведения, используйте следующие параметры при экспорте:
- **Кодек:** H.265 (HEVC)
- **Битрейт:** < 5 Mbps
- **Разрешение:** 4K (3840x2160) или 1080p
- **Длительность:** до 30 секунд

### Поля в таблице `videos`:
- `scenario_id`: Связь со сценарием (выберите из списка).
- `storage_path`: Путь к файлу в бакете `videos`.
- `highlights`: JSON-массив строк (особенности). Пример: `["Панорамный вид", "Тихий двор"]`.

---

## 4. Обновление контента (Workflow)

1. **Загрузите файл:** Перейдите в раздел `Storage`, выберите бакет `videos` или `assets` и загрузите файл.
2. **Создайте запись:** Перейдите в `Table Editor` → `videos`, нажмите `Insert Row`.
3. **Укажите путь:** Вставьте относительный путь к файлу (например, `scenarios/family_intro.mp4`).
4. **Проверьте приложение:** Благодаря движку **AWE (Antigravity Workflow Engine)**, приложение автоматически подтянет новый контент при следующем запуске или при «Pull-to-refresh».

---

## 5. Поддержка и бэкапы

- **Бэкапы:** Выполняются автоматически каждые 24 часа через GitHub Actions.
- **Офлайн:** Приложение кэширует последние загруженные данные. Если интернет пропадет, Showcase продолжит работать на последнем актуальном контенте.
