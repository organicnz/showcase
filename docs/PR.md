# PR: Showcase — Плеер презентаций · Итерация 1

## Описание

Реализация основного приложения-плеера для офиса продаж Мещерского парка. Приложение работает на планшете (iPad/Android), показывает курированные видеосценарии на зеркалированном ТВ-экране и управляется через CMS на базе Supabase.

---

## Что вошло в PR

### Архитектура и настройка проекта
- Проект на Swift 6.3 со строгим контролем параллелизма
- Конфигурация SKIP для транспиляции Swift → Kotlin/Jetpack Compose
- Настройка клиента Supabase с конфигом на основе окружения (dev / prod)
- Структура проекта: `Features/` `Core/` `Design/` `SKIP/`

### Бэкенд Supabase
- Схема: таблицы `scenarios`, `videos` (см. `supabase/migrations/`)
- Бакет Supabase Storage: `videos` с публичным CDN-доступом
- Политики безопасности на уровне строк (RLS): только чтение для приложения, только admin для записи через CMS
- Edge-функция: `GET /scenarios` возвращает активные сценарии с упорядоченными видео

### Экраны SwiftUI (iOS/iPadOS 26 · Liquid Glass)
- `MainScreen` — сетка сценариев, нажатие для воспроизведения
- `LibraryScreen` — полный каталог видео, фильтрация по сценариям
- `PlayerScreen` — полноэкранное воспроизведение на внешнем дисплее, управление только на планшете
- `ServiceStates` — состояния загрузки, офлайн, пусто

### Android-таргет через SKIP
- Эквиваленты Jetpack Compose автоматически генерируются через SKIP
- Скрипт сборки APK: `scripts/build-android.sh`
- Проверено на Android 12+

### Беспроводное зеркалирование экрана
- Управление сессией AirPlay (iOS → Apple TV / smart TV)
- Обнаружение внешнего дисплея через `UIScreen.screens`
- Плеер рендерит на внешний дисплей; управление остаётся на планшете

### GitHub CI/CD — бэкапы Supabase
- `.github/workflows/backup.yml` — ежедневный pg_dump в 02:00 UTC
- Бэкап хранится в ветке `backups/`, автокоммит
- Требуется секрет: `SUPABASE_DB_URL`

## Экраны

| Экран | Маршрут | Примечания |
|---|---|---|
| Главный | `/` | Сетка сценариев, для менеджера |
| Каталог | `/library` | Полный каталог + фильтрация |
| Плеер | `/player/:id` | Только внешний дисплей |
| Служебные | `/loading` `/offline` | Крайние состояния |

## Схема Supabase

```sql
-- scenarios
id uuid PK · title text · slug text UNIQUE · order_index int · active bool

-- videos
id uuid PK · scenario_id FK · title text · storage_path text
duration_sec int · order_index int · active bool · created_at timestamptz
```
